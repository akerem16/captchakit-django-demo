captchakit + Django demo

Bu site, captchakit kütüphanesinin Django ve Django REST Framework ile nasıl kullanıldığını gösteren küçük bir örnek uygulamadır. Kayıt ve giriş formları ile API uçları captcha ile korunur.

Formlar

Kayıt olun ya da giriş yapın: iki form da görseldeki karakterleri sorar.

API

Uçların tamamı /api/docs/ adresindeki Swagger arayüzünde denenebilir. Komut satırından: 

# 1) Captcha al (IP başına sınırlı)
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/captcha/
# → {"id": "…", "image_url": "…/captcha/….png", "expires_in": 180}

# 2) Görseldeki karakterlerle kayıt ol
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/register/ \
  -H "Content-Type: application/json" \
  -d '{"username": "ayse", "password": "…", "captcha_id": "…", "captcha_answer": "…"}'

# 3) Yeni bir captcha ile token al, sonra profili oku
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/token/ -H "Content-Type: application/json" \
  -d '{"username": "ayse", "password": "…", "captcha_id": "…", "captcha_answer": "…"}'
curl {{ request.scheme }}://{{ request.get_host }}/api/me/ -H "Authorization: Token …"

Captcha hataları: 400 yanlış/boş, 404 bilinmeyen ya da kullanılmış, 410 süresi dolmuş, 429 deneme hakkı bitti ya da çok fazla istek.

Nasıl çalışır?

  1. Sunucu bir captcha üretir ve kimliğini (id) formda gizli alan olarak gönderir.
  2. Görsel /captcha/<id>.png adresinden yüklenir.
  3. Form gönderilince cevap sunucuda doğrulanır; her captcha yalnızca bir kez kullanılabilir.
