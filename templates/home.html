{% translate "How it works" %}

  1. {% translate "The server creates a captcha and sends its id with the form." %}
  2. {% blocktranslate trimmed %}The image is loaded from /captcha/<id>.png.{% endblocktranslate %}
  3. {% translate "On submit the server checks the answer. Each captcha works only once." %}

{% translate "Try the API" %}

{% url 'api-docs' as docs_url %} {% blocktranslate trimmed %} Every endpoint can be tried in the interactive API docs. From a terminal: {% endblocktranslate %} 

# 1) {% translate "Get a captcha (rate limited per IP)" %}
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/captcha/
# → {"id": "…", "image_url": "…/captcha/….png", "expires_in": 180}

# 2) {% translate "Register with the characters from the image" %}
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/register/ \
  -H "Content-Type: application/json" \
  -d '{"username": "ayse", "password": "…", "captcha_id": "…", "captcha_answer": "…"}'

# 3) {% translate "Log in with a new captcha, then read your profile" %}
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/token/ -H "Content-Type: application/json" \
  -d '{"username": "ayse", "password": "…", "captcha_id": "…", "captcha_answer": "…"}'
curl {{ request.scheme }}://{{ request.get_host }}/api/me/ -H "Authorization: Token …"

{% blocktranslate trimmed %} Captcha errors: 400 wrong or missing, 404 unknown or already used, 410 expired, 429 too many attempts or requests. Send Accept-Language: tr for Turkish messages. {% endblocktranslate %}
